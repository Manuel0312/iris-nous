Iris Nous

App sull’iPhone

L’app vera è quella nativa (stessa UI dell’anteprima sul sito). Non serve «Aggiungi a Home» su /app.

Subito (Sideloadly)

  1. Sul PC: Sideloadly + IPA in Desktop → app iris → iphone.
  2. Collega l’iPhone → Start → autorizza il profilo in Impostazioni.
  3. Apri Iris Nous: vedi Connessioni, Iris e Account come in anteprima.

Sicurezza anti-manomissione

Usa solo l’IPA Iris ufficiale. Confronta lo SHA-256 con il manifesto del sito prima di firmarlo con Sideloadly. Un file diverso non è la build Iris.

Manifest: /api/mobile/integrity

Prova dal sito

Sul computer apri l’anteprima (telefono mock). Sul telefono usa l’app nativa.
